# Swasthika Rajarathinam - React Portfolio

A modern responsive portfolio built with React + Vite.

## Run locally

1. Install Node.js (LTS).
2. Open this project folder in VS Code.
3. Open a terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite.

## Add your resume

Copy your final resume PDF into:

`public/resume.pdf`

The Resume buttons will then download it.

## Build for deployment

```bash
npm run build
```

The production files will be created in `dist/`.
